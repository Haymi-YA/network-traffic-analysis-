# Network Traffic Analysis and Security Investigations

## About This Repository

This repository documents my practical learning journey in network traffic analysis and network security using Wireshark.

It contains hands-on investigations of different network protocols, communication patterns, and security-related activities using publicly available or controlled sample PCAP files.

The objective is to develop practical skills in packet analysis, network troubleshooting, security monitoring, and incident investigation.

## Objectives

- Understand network protocols and communication.
- Analyze packet captures using Wireshark.
- Identify source and destination addresses.
- Investigate DNS, TCP, UDP, HTTP, HTTPS, TLS and SSH traffic.
- Understand suspicious network activities.
- Apply network traffic analysis techniques to security investigations.
- Document findings and recommend defensive measures.

## Tools and Technologies

- Wireshark
- Windows
- PCAP analysis
- Networking protocols
- Display filters

## Investigation Areas

| Area | Description |
|---|---|
| DNS Analysis | Domain resolution and DNS traffic |
| TCP/UDP Analysis | Transport-layer communication |
| HTTP/HTTPS/TLS | Web and encrypted communication |
| SSH/SCP | Secure remote access and file transfers |
| Email Protocols | Email-related network traffic |
| Network Attack Analysis | Controlled security investigations |
| DHCP/ARP/ICMP | Network communication and diagnostics |
| Full Investigations | Multi-protocol security investigations |

## Investigation Methodology

Each investigation includes:

1. Project overview and objectives.
2. Tools and lab environment.
3. Investigation methodology.
4. Wireshark display filters.
5. Packet observations and findings.
6. Security implications.
7. Recommendations.
8. Lessons learned.

## Disclaimer

This repository is intended for educational and defensive cybersecurity learning.

Investigations use authorized lab environments and publicly available or appropriately licensed sample captures. No unauthorized network activity is conducted.

This repository is continuously updated as I develop my network security and cybersecurity investigation skills.
